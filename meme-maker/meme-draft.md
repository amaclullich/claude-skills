# Meme Draft

Generate meme text in a simple copy-paste format for manual entry into SuperMeme or Canva.

## Usage
```
/meme-draft [fact or topic]
```

## Output Format

```
TEMPLATE: [Template Name]
---
[Zone 1 label]: [text]
[Zone 2 label]: [text]
[Zone 3 label]: [text] (if applicable)
---
CAPTION: [social media caption]
```

## Example Output

```
TEMPLATE: Drake
---
TOP: Spending 2 minutes on a 4AT screen
BOTTOM: Spending 3 weeks managing the ICU admission it would have prevented
---
CAPTION: The economics of delirium care make no sense.
```

## Instructions

1. Read the fact/topic provided
2. Select an appropriate template
3. Output ONLY the template name, zone text, and caption
4. No markdown tables, no pattern explanations, no metadata
5. Ready for direct copy-paste into meme creation tools
